# daily-report

TME 工作日报/周报生成 Skill，用于 Claude Code。

## 功能

- **日报生成** — 根据最近工作上下文，按固定格式生成日报并保存到 Bear 笔记
- **周报生成** — 聚合本周日报，合并动作链生成周报
- **实时更新** — 支持全天随时补充/修正日报内容（新增事项、状态变更、补充计划）

## 安装

```bash
mkdir -p ~/.claude/skills/daily-report
```

将 `SKILL.md` 放入 `~/.claude/skills/daily-report/` 目录即可。Claude Code 会自动发现并加载。

## 使用

在 Claude Code 对话中直接说：

- 「写日报」
- 「写周报」
- 「补充下明天的计划」
- 「更新日报，灵动调节今天转体验了」

## 日报格式

```
# YYYYMMDD | 日报
#tme/meeting/YYYY/MM

## ❮ 昨天的进展
1、🔨 版本号 【模块】需求名称（状态）
* 具体工作项

## ❙ 今天的工作
（同上结构）

## ❯ 明天的计划
（创建时留空，后续可补充）
```

### 工作项类型

| Emoji | 类型 | 说明 |
|-------|------|------|
| 🔨 | 需求开发 | 含状态标签：评估中 → 开发中 → 转体验 → 测试中 → 已发布 |
| 🐛 | 问题跟进 | Bug / 线上问题 |
| 🎯 | OKR | 目标类事项 |
| 📌 | 其他 | 会议、分享等 |

## 核心规则

1. **不编造** — 所有工作项必须由用户提供
2. **先确认再写入** — 内容确认后才创建/更新 Bear 笔记

## 依赖

- Bear 笔记应用
- Claude Code Bear MCP 工具 (`mcp__bear__*`)
